📒 安装「加生词」按钮

看 YouTube / 上网时，选中单词一键收进「待整理队列」，发给 Claude 做成完整词条

方法一 · 最简单（电脑）：拖一下

把下面这个按钮，用鼠标拖到浏览器顶部的书签栏上松手，就装好了：

📒 加生词

看不到书签栏？按 ⌘+Shift+B 显示出来（Windows 用 Ctrl+Shift+B），再拖。

方法二 · 手动添加（拖不动时用）

  1. 书签栏空白处右键 → 添加页面 / Add page
  2. 名称填：📒 加生词
  3. 网址栏：把下面整段粘进去（务必含开头的 javascript:，被吞掉就手动补上）
  4. 保存
javascript:(function(){var u='https://ruilearning-my.pages.dev/';var w=(window.getSelection().toString()||prompt('加入生词本：')||'').trim();if(w)window.open(u+'#add='+encodeURIComponent(w),'vocab','width=360,height=210');})()

怎么用

  1. 看到能选的字（标题/简介/评论/字幕）→ 选中单词 → 点书签
  2. 只是听到、没字可选 → 直接点书签 → 弹框里敲进去回车

点完会弹一个小窗显示「✓ 已收：词」，约 1 秒自动关闭，不会展示整页笔记本。收的词进「待整理队列」（跨设备同步）。攒一批后，跟 Claude 说「整理我的草稿」，我做成完整词条再部署，它才进正式列表。

手机怎么办

手机没有书签栏、书签难点。手机上直接打开 ruilearning-my.pages.dev，用页面里「📥 快速收集」框粘词收集即可（同样进待整理队列）。

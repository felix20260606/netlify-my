# LearnVocab

个人英语学习工具。看 YouTube 时显示双语字幕、查词、收集生词，再把生词送进自己的生词本网页整理。

| 目录 | 内容 |
|---|---|
| `extension/` | 浏览器插件「双语字幕 · 生词收集」（图标为 BAN）（Manifest V3，Chrome / Brave / Edge） |
| `site/` | 生词本网页（单文件 `index.html`，部署在 Netlify）和加词书签安装页 |
| `tests/` | Playwright 回归测试脚本（加载插件 + 模拟的 YouTube 页面） |

插件的使用习惯对齐 Language Reactor（下文简称 LR）：功能和操作方式一致，代码、图标、名称都是自己的，不使用 LR 的服务器。

## 安装与更新

1. 打开 `chrome://extensions`（Brave 为 `brave://extensions`），右上角开启「开发者模式」。
2. 点「加载已解压的扩展程序」，选择 `extension/` 文件夹。这个文件夹不能删，插件一直引用它。
3. 打开任意 YouTube 视频，播放器控制条上出现「BAN ON」图标就是装好了。

更新：覆盖 `extension/` 里的文件后，在扩展页点插件卡片上的「重新加载」，再刷新 YouTube 页面。已经开着的视频页不刷新也能继续用，但用的是旧版本。

不要和 Language Reactor 同时启用，两套字幕会叠在一起。

## 字幕

### 来源

- **原文**：YouTube 自带的字幕轨。插件在页面里拦截 YouTube 自己发出的字幕请求，拿到带令牌的地址后改成 JSON 格式重新取一次。所以视频必须有字幕（人工的或自动生成的都行），并且 CC 要处于可用状态；插件会自动尝试打开 CC。
- **翻译**：默认用 YouTube 的自动翻译（和 LR 的来源相同）。可在设置里换成 Google 翻译或微软翻译。
- **视频没有学习语言的字幕轨时**（例如中文视频只有中文字幕）：和 LR 一样，让 YouTube 把现有字幕自动翻译成学习语言当作原文；如果现有字幕正好是翻译语言，就直接把它当翻译行。
- **人工翻译**：视频自带目标语言的人工字幕时，可以另外显示一行。

### 文本处理

- 清理 HTML 实体、零宽字符、`>>` 说话人标记；`--` 换成破折号；直引号换成弯引号。
- `(Laughter)`、`[Music]` 这类提示单独标成注释行，最长显示 2 秒。
- 自动生成的字幕（ASR）每行很短，会把相邻两行配成一句（间隔小于 1.5 秒、总长小于 110 字符）。
- 可选「按整句合并字幕」：把被拆成几行的一句话合成一条。
- 中文翻译里汉字之间多余的空格会去掉。

### 显示时机

- 一句结束后字幕不消失，停在当前句，直到下一句开始才切换。
- 开着自动暂停时，暂停点在句末前约 0.12 秒；暂停期间锁定当前句，不会提前显示下一句。

### 隐藏字幕（练听力用）

设置里的「隐藏字幕」有五个选项：禁用、隐藏翻译、隐藏字幕、先显示翻译再显示字幕、先显示字幕再显示翻译。

- 被隐藏的行模糊显示。
- 暂停不会自动显示。
- 鼠标移到或点击某一行，只显示那一行，这一句内保持显示。
- 按 `E` 按模式的顺序逐行显示。
- 换到下一句重新隐藏。

## 查词

### 悬停：小气泡

- 两三个中文释义。
- 词频条：越长越生僻。
- 短语：如果这个词和前后词组成短语（如 `a week later`、`two weeks`、`got it`），先显示短语和它的翻译。短语靠 Wiktionary 是否有这个词条，加上一组时间短语规则来判断。
- 不规则变形：显示原形及释义（`wrote` → `write`）。
- 缩写：先展开再翻译（`I'd` → `I would`）。
- 语法：带语法下划线的词会多一行说明，如「语法：过去时」。
- 可选「显示迷你词典时自动暂停」：悬停时暂停视频，移开后继续。

每句字幕出现时，会提前把这一句里的生词查好，悬停时直接显示。查过的词存在本地，下次不用联网。查询失败不会被记住，下次悬停会重查；插件后台连不上时，页面会自己直接查。

### 点击：词典面板

停靠在播放器右侧，包含：

- 单词、音标（Datamuse 的发音数据转成 IPA）、朗读。
- 中文释义按词性分组，英文释义来自 Wiktionary。
- 词频条和词频排名。
- 标记按钮：✓ 已掌握、📖 将要学习、⊘ 不学习。
- 外部词典链接：Reverso、Cambridge、WordReference、Google、Wiktionary、百度，以及你在设置里加的自定义网址。
- 「示例：当前文本」：这个词在本视频里出现的句子，可以点播放、收藏。
- 面板里的单词同样可以悬停、点击、右键标记。

### 右键：标记

- 没有框的词：右键直接加入「将要学习」。
- 已经在学习的词（黄框）：右键标为「已掌握」。

- **短语一起保存**：把一个词加入学习时，如果它在一个短语里（如 a week later、got it），这个短语连同所在的原句、原声、画面和出处一起存进「保存的短语」，并进入待整理队列。可在设置里关掉。

## 单词颜色与词汇水平

在设置里点「设置词汇水平与单词颜色」，选择你大约认识多少个常用词（词汇水平）和「建议学习」的范围比率。

| 类别 | 判断方式 | 默认显示 |
|---|---|---|
| 已掌握 | 词频排名在你的水平以内，或手动标记 | 白色（可选绿色） |
| 建议学习 | 排名在「水平」到「水平 + max(水平, 300) × 比率」之间 | 橙色 |
| 更生僻 | 排名超出建议范围 | 紫色 |
| 将要学习 | 你右键或在词典里标记的词 | 淡黄色框 |
| 不学习 | 手动标记 | 紫色 |
| 特殊词汇 | 数字、数词、全大写缩写、句中首字母大写的人名地名 | 绿色 |

- **你自己的标记按原形生效**：保存了 write，字幕里的 wrote、written、writes 也带黄框；标 going 为已掌握，go、went 也算已掌握。词频表里查不到原形的生僻词（如 reinvented）按词尾规则归并。「所有单词」页只列原形，用的是和字幕上色同一个判断函数，两边状态一致。
- 词频表是 OpenSubtitles 字幕语料的前 22000 个词，按原形判断难度（`papers` 按 `paper` 算）。
- 想让着色接近 LR：水平选 700，比率选 2.0x。在同一个 TED 视频上和 LR 对比，624 个不同的词里 93% 颜色一致。

## 语法下划线

把英语里中文没有或很少有的形式用下划线标出来。这是 LR 没有的功能。

| 下划线 | 含义 | 例子 |
|---|---|---|
| 蓝色实线 | 过去时 | wrote、turned、were |
| 青色双线 | 完成时 | have written、having written |
| 绿色波浪线 | 进行时 | is working |
| 粉色虚线 | 将来 / 情态 | will、would、is going to |
| 橙红粗线 | 被动语态 | was written、are supposed |
| 蓝色点线 | 第三人称单数 | writes、doesn't |
| 灰色点线 | 复数 | months、words |
| 黄色点线 | 冠词 | a、the |
| 紫色虚线 | 比较级 / 最高级 | bigger、most |
| 词上方红线 | 否定缩写 | didn't |

- 字幕和右侧栏里都会标，和单词颜色互不影响。
- 设置里有总开关，十类也可以各自单独开关。
- 判断靠词形、一张不规则动词表和前后几个词，不是真正的语法分析，会有少量标错。最容易错的是 -ed 结尾的形容词被当成过去时，以及 -s 结尾的词在复数和第三人称单数之间判断错。
- 一个词只标一种时态：`have been working` 里 `have been` 标完成时，`working` 标进行时。

## 右侧栏：字幕 / 词语 / 已保存

顶部工具：📄 载入字幕文件、↻ 重新获取字幕、⤓ 导出、⚙ 设置、✕ 收起。

点 ✕ 不是关闭，而是收起成一条「字幕（隐藏）」，点一下展开。想彻底不显示，在设置里关掉「显示字幕列表视图」。

### 字幕

- 每行只显示原文，当前句高亮并自动滚动到中间。
- 翻译的显示方式可在设置里选：「悬停时弹框显示」（默认，和 LR 一样）或「显示在列表里」（每行原文下面直接带翻译，这时气泡只显示单词和短语）。
- 悬停一行：左边出现播放按钮，右边出现 ☆（保存这句）。
- 悬停单词：气泡出现在侧栏左侧，依次是短语、单词释义（带词频条）、语法、整句翻译。悬停行内空白处只显示整句翻译。
- 点击单词开词典；点击行或播放按钮跳到那一句。
- 手动滚动后停止自动跟随，右上角出现紫色圆形按钮，点它回到当前句并恢复跟随。

### 词语

三个视图：

- **学习**：进度条「你已掌握 X% 的单词」和「学习 20 个单词即可达到 Y%」。按 0–10 min、10–20 min 分段列出推荐词，每个词有序号、出现次数、两个释义、📖 按钮，后面跟最多 6 句视频里的例句。底部有「标记为正在学习 (20)」和翻页。推荐顺序按「出现次数 ÷ 生僻程度」排，常用且出现多的排前面。
- **词频排名**：✓ 已掌握 / 📖 学习中 / ⊘ 不学 三个计数（点击可筛选）和总词数。按 Rank 1–100 … 8001+ 分段，段内按出现次数（100+、50+、20+、10+、5+、4、3、2、1）分组。
- **视频中出现次数**：只按出现次数分组，词多的组再按首字母分。

### 已保存

- 「查看全部」打开完整的已保存页面。
- 「最近保存」按时间倒序，单词标 `w`，句子标 `p`。
- 「显示上下文」开关：打开后单词显示保存时所在的那句话。旧的没有记录原句的词，会从当前视频里找一句包含它的句子补上。
- 最底部是「生词本待整理队列」，可以一键复制。

## 已保存项目页

参考 LR 的“已保存项目”做的完整页面。入口：右侧栏「已保存」页的「查看全部」，或设置里「词汇」一组的「查看全部 ›」。

- **保存的单词**：搜索、按来源视频筛选、按日期 / 频率 / 待复习排序；三个状态切换（标记为已知、标记为将要学习、不学习）和各自的数量；按保存日期分组的表格，每行有播放（有原声放原声，否则朗读）、单词、翻译、词频排名、上下文（目标词带框）、复习阶段、来源（画面缩略图和视频标题，点击回到视频的那一句）。勾选后可以批量标为已知、复制、删除。
- **保存的短语**：用 ☆ 保存的句子，同样可以播放原声、搜索、按来源筛选、批量复制和删除。
- **所有单词**：词频表里最常用的 22000 个词，每 100 个一段、段内按首字母排；颜色表示状态，顶部显示“已掌握（自己标记 + 按水平推测）/ 学习中 + 建议 / 不学习 + 罕见”的数量。右键点击单词可以加入学习或标为已掌握。

颜色标签（绿、黄、红、蓝）：勾选后在工具条里打标签，顶部的 `/` 和四个 `#` 用来按标签筛选。“所有单词”可以切换 频率 / A–Z 排序和 单元格 / 行 两种显示。

---

操作方式（三个页面通用，和 LR 一致）：

- **鼠标放到单词上**：小气泡显示两三个释义，带“已掌握”和“学习中”两个快速标记按钮。
- **点击单词**：右侧打开词典面板，包含可以改写的搜索框、朗读、词频条和排名、三个标记按钮；点展开箭头可以看每种标记的含义、打颜色标签、设为“下次学习”（下一次复习从它开始）；下面是中文释义、你保存时的句子（带画面、出处和原声）、英文释义、例句和外部词典链接。
- **所有单词页顶部的六个数字**（自己标记的三类加按水平推测的三类）可以点击，只看那一类。

## 复习

参考 LR 的 PhrasePump 做的单词复习页。入口：右侧栏「已保存」页的「练习」按钮，或设置里「词汇」一组的「复习 ›」。

- **首页**：今天练了多少张卡片；待复习、学习中、已学会三个数字；会话选项（测验、练习、练习数量、新项目比例、自动朗读）。
- **听力卡**（“练习：先理解再显示”）：朗读一个包含目标词的例句，原文和翻译先模糊。按 `E` 显示原文，再按一次显示翻译；`S` 重听；`X` 标为“还不会”；`D` 下一张；`A` 上一张。
- **填空卡**（“测验”）：例句里的目标词挖空，给出翻译，输入后按回车检查。按 `E` 直接看答案算没答对。
- **原声、画面和出处**：看视频时每句字幕播放的同时会把这一句的声音录下来；保存单词或句子时，把这一句的原声、当时的画面截图和出处（视频标题、频道、时间）一起存在本地。复习时卡片显示画面和出处（点出处回到视频的那一句），播放的是原声。保存时这一句还没播完的，播完后自动补上原声；句子中途暂停（如悬停查词）不会丢录音。如果保存的那一句根本没有从头播过（从中间开始播的、还没播到的），会在视频暂停时自动补录：静音回放这一句把声音录下来，再回到原来的位置。可在设置里关掉「保存时存下原声和画面」。更新前保存的词没有这些，仍用例句库和合成语音。
- **例句来源**：Tatoeba 例句库（CC-BY，带中文翻译）；查不到时用保存这个词时所在的那句字幕；再没有就只练这个词本身。朗读用浏览器自带的语音。
- **间隔重复**：答对一次升一级，下次复习间隔依次是 1 天、3 天、7 天、16 天、35 天、90 天；没答对回到起点，10 分钟后再出现。升到 35 天这一级算“已学会”。
- 复习记录存在浏览器本地（`srs`），不上传。

和 PhrasePump 的差别：没有“建议新词”（它会从你看过的内容里推荐没保存的词）、没有按颜色标签筛选；例句和语音不是同一来源。

## 播放控制与快捷键

| 键 | 功能 |
|---|---|
| `A` / `S` / `D` | 上一句 / 重复当前句 / 下一句 |
| `Space` | 播放 / 暂停 |
| `Q` | 开关自动暂停（AP） |
| `R` | 保存当前句子 |
| `E` | 显示被隐藏的字幕或翻译 |
| `Ctrl/⌘ + C` | 复制当前句子 |
| `O` | 单句循环 |
| `Z` / `X` | 减速 / 加速 |
| `←` `↓` `→` | 上一句 / 重复 / 下一句（需在设置里开启「覆盖方向键」） |

`L`、`T` 等 YouTube 自带的快捷键不占用。

鼠标：左键查词典，右键标记单词。

## 生词本同步

「将要学习」的词除了存在浏览器本地，还会追加到 JSONBin 上的「待整理队列」。生词本网页读取这个队列，整理成完整词条。

## 与 Language Reactor 的对比

在同一个视频上并排对比过的结果：

| 项目 | 结果 |
|---|---|
| 人工字幕视频：原文分句 | 38 句里 37 句一致 |
| 人工字幕视频：翻译 | 38 句里 36 句一致 |
| 人工字幕视频：单词颜色 | 260 个词里 251 个一致 |
| 自动字幕视频：原文分句 | 20 句里 17 句一致 |
| 词语页「已掌握」比例 | LR 83%，本插件 84% |
| 自动暂停时显示的句子 | 连续 7 句与 LR 相同 |

行为已对齐的部分：字幕位置和控件布局、隐藏字幕的五种模式、悬停气泡和点击词典、侧栏三个标签页、✕ 收起、回到当前句按钮、快捷键、右键标记。

没有做的：

- 词频排名里的四个彩色 `#` 标签。
- 字幕行右侧的 `⋮` 菜单。
- Netflix 等其他网站。

仍有差别的：

- 个别单词的中文释义用词不同（词典数据不是同一份）。
- 约 4%–7% 的单词颜色不同（词频数据不是同一份）。
- 词频排名的总词数偏多（词形归并不如 LR 细，如 `going` 和 `go` 算成两个词）。
- 自动字幕里音乐提示和说话的先后顺序偶尔不同。

本插件比 LR 多的：语法下划线、生词本待整理队列同步、自定义翻译引擎。

## 代码结构

```
extension/
  manifest.json        清单（MV3）
  inject.js            运行在页面主环境：拦截 YouTube 的字幕请求，读写字幕轨和音频轨
  freq.js              词频表（VS_RANK）
  vlevel.js            词形还原、单词分类（vsCat）、给文本加颜色标记（vsMark）
  gram.js              语法识别（vsGram）和给标记后的文本加下划线类名（vsGramHtml）
  content.js           主逻辑：字幕、气泡、词典、侧栏、快捷键
  content.css          页面内所有样式
  background.js        后台：翻译、查词、短语检查、音标、生词同步
  config.example.js    同步密钥模板（复制为 config.js）
  popup.html / .js     设置页（工具栏弹窗和页面内弹窗共用）
  level.html / .js     词汇水平与单词颜色设置页
  tiers.js             词汇水平分档数据
  saved.html / .js     已保存内容的完整页面
  review.html / .js    单词复习页（听力卡、填空卡、间隔重复）
  icons/               图标
```

内容脚本的加载顺序：`inject.js`（主环境，文档开始时）→ `freq.js` → `vlevel.js` → `gram.js` → `content.js`。

### 关键流程

1. `inject.js` 给 `XMLHttpRequest` 和 `fetch` 打补丁，看到 `/api/timedtext` 请求就把地址发给内容脚本。
2. `content.js` 用这个地址加 `fmt=json3` 重新请求原文；加 `tlang=zh-Hans` 请求 YouTube 的自动翻译。
3. 解析、清理、分句，得到 `cues`（每条有开始时间、结束时间、文本）。
4. 每 100 毫秒检查一次播放位置，找到当前句并渲染；自动暂停临近句末时改用精确计时。
5. 渲染时文本依次经过 `vsMark`（颜色）和 `vsGramHtml`（下划线）。
6. 悬停和点击通过消息向 `background.js` 请求释义；后台不可用时内容脚本自己直接请求。

### 开发用的钩子

`content.js` 里留了三个给自动化测试和远程更新用的消息入口，正式发布前应删掉：

- `postMessage({src:'VS', type:'reload-ext'})`：让插件重新加载自己。
- `type:'dev-level'`：直接设置词汇水平和比率。
- `type:'dev-state'`：返回当前部分设置。

## 已知问题

- 视频没有任何字幕轨时插件无法工作，除非手动载入字幕文件。
- Google 翻译接口偶尔限流，表现为悬停气泡暂时没有释义；再悬停一次会重查。
- 微软翻译引擎和音频轨道切换没有充分测试。
- 全屏模式下的表现没有逐项核对。
- 语法下划线会有标错，见上文。
- `site/` 里的生词本网页和 Netlify 上的版本需要手动部署，仓库里的密钥是占位符。

## 同步到生词本网站（手机随时复习）

- 在视频里把单词标为“正在学习”（或保存短语）时，扩展会直接在云端生成一条**完整词条**：中文释义、音标、英文释义、视频原句及其翻译，标签为“视频”。
- 生词本网站（同一个 JSONBin）打开后会自动拉取，这些词立刻出现在列表、背诵和自测里，手机、电脑都一样。
- 设置页“词汇”一栏的 **同步到生词本网站 ›** 可以把本机已保存的词和云端“待整理队列”里的词一次补齐；更新后首次打开 YouTube 也会自动补齐一次。
- 连续加词时云端写入是串行的，不会互相覆盖；同名词条不会重复添加。
- 测试：`tests/t38.js`（词条生成、去重、并发写入、补齐）。

## 手机上边看边学（网站「🎬 视频」）

- 生词本网站实际部署自另一个仓库 `felix20260606/netlify-my`（推送即自动部署）；本仓库 `site/` 只是早期副本，不再是线上版本。
